# Runtime qualification remains separate

No runtime MCP launch operation is currently enabled. Keep log ingestion,
structured export triggering, scenario launch and completion observation as
separate capabilities. A recorded log or metadata inventory does not establish
actual command support or complete preservation.

Future qualification uses an explicitly approved, build-scoped disposable setup,
archives raw evidence, positively observes start/assertions/completion, and checks
all originals. Missing execution or completion remains not-run/incomplete. Never
clear unrelated logs or infer success from absence of errors.
