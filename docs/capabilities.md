# Capability boundaries

`lab_capabilities` is the runtime source of profile-specific availability. Tools
register only when their operation works; missing operations are not advertised
as successful stubs.

| Capability | Available scope |
|---|---|
| Aggregate election research and error scenarios | Explicit election-research profile; public dated partial snapshots; no chamber odds or demographic inference |
| Core diagnostics, runs, bounded artifacts | Local selected instance; artifacts retain profile/disclosure checks |
| EU5 static scan and inspection | Synthetic fixtures and configured read-only roots; coverage remains explicit |
| EU5 staged repair and experimental export | Supported deterministic edits, revision/hash checks, full preservation gates |
| EU5 deployment-plan preparation | Immutable review plan; external apply unavailable pending qualification |
| CK3 investigation and saved discussion | Current permitted captured sources; historical freshness and exclusions explicit |
| CK3 reviewed inactive call-allies changes/undo | Exact scoped native/terminal decisions; original mods unchanged |
| Game launch, activation, live undo | Unavailable; relocation does not approve pending probes |
| Native Windows production deployment | Unqualified in this migration; offline Windows CI is separate |
| Model calls | Disabled on the default path; optional inference adapter retained |

A parsed file, selected static winner, empty log or synthetic success does not
establish preserved gameplay. Documentation, inspected source, inferred behavior,
synthetic contracts and executed game observations remain distinct.
